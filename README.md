
# Employee Attrition Analysis & HR Analytics Dashboard

## Project Overview
This project presents an interactive HR Analytics Dashboard created using Power BI to analyze employee attrition and workforce-related KPIs.

## Tools & Skills
- Power BI
- DAX
- Data Cleaning & Transformation
- Data Visualization
- Data Analysis

## Dashboard KPIs
- Total Employees
- Total Attrition
- Attrition Rate
- Active Employees
- Average Age
- Average Monthly Pay

## Key Analysis
The dashboard analyzes employee attrition by:
- Age Group
- Gender
- Department
- Job Role
- Education Field
- Business Travel
